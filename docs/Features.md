# Features

## Overall

- Daemon backend running in the background - control your playback across terminals
- Remote control

## Playback

- Control it via terminal command / TUI / tray icon / media key
- Memorized progress - continue where you left
- Resume last session on startup - continue to continue where you left
- Loop / Shuffle / Reverse mode
- **Real time lyric from local/online source** - all automatically
- Dual audio engine: VLC x miniaudio

## Library

- Add easy-to-remember aliases to your songs so you can reference them easily
- Scan all audio files under a directory and add them to library - recursion scanning available
- Download lyrics from multiple online sources
- Classify your songs into playlists

## Configuration

- Customize everything - Audio engine, TUI appearance, and more
- Modify options conveniently via GUI window
